# BRODEZ\n\n**BRODEZ Studio** est un studio web local-first de création de motifs de broderie au point de croix.\n\n## Ce qui est réellement fonctionnel\n\n- génération de motifs depuis une **intention en langage naturel** ;\n- interprétation de dimensions (`60 × 60`, `80 × 60`, etc.) et d'un nombre de couleurs ;\n- génération déterministe de compositions pour plusieurs familles de sujets ;\n- palette DMC embarquée avec références et couleurs ;\n- grille éditable case par case ;\n- ajout / retrait de points par clic ;\n- vues **2D**, **3D/perspective**, **patron** et **fils** ;\n- zoom, sélection, annulation et rétablissement ;\n- sauvegarde locale du motif ;\n- import d'une image et conversion en grille DMC ;\n- export **SVG vectoriel**, **CSV de coordonnées** et **JSON source de vérité** ;\n- paramètres de tissu, compte (ct) et nombre de brins ;\n- interface responsive et sans compte.\n\n## Architecture\n\nLe motif est conservé comme une source de vérité unique :\n\n`Pattern → dimensions → grille → points → palette DMC → fabrication → exports`\n\nL'IA peut proposer une intention ; l'utilisateur garde la validation et l'édition du motif.\n\n## Important\n\nLe générateur actuel est un moteur local déterministe. Il ne prétend pas être un modèle d'image génératif ni un convertisseur machine certifié.\n\nLes formats machine **DST / PES / JEF / EXP** ne sont pas déclarés disponibles tant qu'un encodeur et une validation machine réels n'ont pas été implémentés.\n\n## Développement\n\n    npm install\n    npm run dev\n\nBuild de production :\n\n    npm run build\n\n## Prochaine couche\n\nLe modèle est volontairement préparé pour accueillir ensuite :\n- un véritable moteur de composition assistée ;\n- une bibliothèque DMC complète ;\n- des types de points et chemins d'exécution ;\n- une vraie géométrie 3D des fils ;\n- validation de contraintes de broderie ;\n- export machine après validation ;\n- projets persistants et versions.
