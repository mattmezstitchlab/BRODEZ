# Dossier hors service

Ce dossier a été généré par DesignArena. Son ancienne configuration (fichier `vercel.json`) contenait les accès d'une base Supabase.

Le 22 octobre 2026, ces accès ont été retirés du dépôt. Vérifications faites ce jour-là :

- l'adresse de la base Supabase ne répond plus (nom inconnu) : le projet est supprimé ;
- l'organisation Supabase du propriétaire n'a plus aucun projet ;
- aucun projet Vercel du propriétaire ne déploie ce dossier, ni n'utilise de variable Supabase.

Les clés restées dans l'historique Git sont donc historiques et invalides.

Les routes `api/` de ce dossier ne peuvent plus fonctionner sans base de données. Elles sont conservées pour mémoire. Elles ne doivent pas être redéployées telles quelles : elles n'ont pas de contrôle d'accès.
